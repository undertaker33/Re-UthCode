## 1. 背景

两轮独立全仓审查确认：当前 Provider、Tool、Permission、Transcript/Timeline、异步 Compact 与 Eval 的主体复杂度均有现存需求支撑，但正式 `AgentRun/TurnHandle` 之外仍保留早期 Generation facade；固定控制规则外仍存在无生产扩展者的 Hook 框架；Context Compiler 支持多套输入形态；Session v2 强制保存无人写入的 RuntimeLog；命令系统展示未实现能力；多个仅由测试或导出表支撑的 Protocol 与包装类型扩大了维护面。

本任务只删除上述已经确认的提前抽象，不新增 Memory、Dream、Skill、MCP、Runtime checkpoint、动态 Hook 或新的配置能力。

## 2. 用户已确认决策

1. 唯一运行入口为 `create_application -> create_run -> start_turn -> AgentLoop`。
2. `GenerationHandle`、`start_generation()`、`stream_generation()` 与拒绝型 `execute_tool_calls()` 直接删除，不提供弃用期或兼容入口。
3. Session 硬切 v3；v1、v2 均明确 incompatible，不提供迁移、双读或恢复尝试。
4. 公共导出只定点移除本任务确认的冗余符号，不进行全量 API 白名单重设计。
5. 包版本保持 `0.1.0`；本任务不执行 commit、push、merge、tag、release 或归档。

## 3. 交付范围

- 收敛运行入口和固定 Runtime 控制。
- 收敛 Context Source、Compiler 与 estimator 合同。
- 删除空置状态模型并建立 Session v3。
- 删除未来命令占位、PROMPT 命令模式和同步 Dispatcher。
- 删除幽灵 Protocol 与相关公共导出。
- 更新当前事实、用户文档、能力欠账和架构验收。

正式实施边界、任务顺序与验收分别见同目录 Spec、Tasks、Checklist；用户首次显式派发 `prompt/W01-engineering-convergence-prompt.md` 后，这些文件冻结。
