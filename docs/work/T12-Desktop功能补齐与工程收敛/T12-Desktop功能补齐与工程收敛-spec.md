# T12-Desktop功能补齐与工程收敛 — Spec

## 背景

现有 Coding Desktop 已承接正式 Agent 与持久 Session；会话检索/归档、独立通用聊天、连续过程摘要与一致审阅仍缺少正式闭环。Settings 全局提交和命令回执还会破坏编辑连续性。本包以当前源码为依据完成这些已确认能力，并清理被替代实现。

本包源需求为 [T12-Desktop功能补齐与工程收敛.md](T12-Desktop功能补齐与工程收敛.md)。目前处于拆分交付阶段；用户审核本 Spec 与 Checklist 并显式派发 Worker 后才实施。按用户“不新建文件夹”的要求，全部新工作文档和未来 Worker Feedback 平放现有 T12 目录；目录模板例外不改变冻结、反馈、派发和验收规则。

## 目标

- Coding 跨可信已登记项目检索真实公开正文；General 只检索自己的独立用户级会话，归档仍可发现。
- 空闲 Session 幂等归档/恢复，原历史和归属可靠保留；统一在 Settings 管理归档，普通目录和最近列表准确过滤。
- General 提供可配置模型的真实文本流式聊天、取消/失败与持久历史；与 Coding 共享正式底座且互不覆盖导航、草稿及运行。
- 过程段默认聚合，关键说明/交互/失败与最终正文可见；耗时、输出与变更摘要有真实来源，右侧只读审阅一致。
- 设置字段自动安全保存，保存和应用独立可见，活动任务/进程快照保持；模型、权限选择保留未发送草稿。
- 全仓按真实调用证据定点收敛，保留既有安全、权限、持久化和 Headless 合同。

## 非功能要求

- 继续遵守模块化单体依赖方向，所有界面经 Application 使用 Core；单一 Agent Loop、运行状态写入者、Session 存储和用户配置权威保持。
- 搜索、输出、预览与 Diff 有界且可取消；损坏、无权、消失为局部受控失败。模式/项目/会话归属与迟到响应隔离，导航不自动取消后台任务。
- 归档不删历史、不移动/复制 Session、不改原排序时间；操作原子性以单目标元数据为粒度，已有持久业务数据只做必要兼容读取。
- 共享权限、Secret、可信配置、项目收紧、工具执行与进程回收安全边界保持；Bash 仍是用户权限下的非沙箱执行。
- 搜索不包含未公开推理、工具正文、秘密与隐藏诊断；展示只消费 Application 脱敏、有界投影的安全输出，未经处理的原始工具输出不得直接展示。工具执行进度继续只用于有界实时观察。
- 优先复用当前实现和成熟依赖；无真实调用、失败模式或约束不建新抽象，不以行数为瘦身目标，不为未来能力造目录/状态/框架。

## 设计骨架

界面分 Coding 与 General 两个导航视图，各自保留选择、历史与草稿，使用同一 Application/Run/Provider/Context/Session。General 的可信用户级归属、最小非 Coding 指令和无默认工具语义在创建、恢复、配置刷新后均一致；旧会话继续属于 Coding。

Session 归档由唯一持久元数据提供事实。搜索从可信范围按需读正式公开文本，不构造每个会话的运行时。归档按目标会话实际活动状态拒绝，无关活动会话不阻断；已归档搜索结果显示状态，通过明确流程恢复。

过程组由安全事件与回放派生，按公开说明、用户输入、关键交互和失败分段；有证据才展示历时与安全输出。历史变更摘要归属已完成 Turn，当前 Git Diff 标注查看时状态；无充分证据不合成历史版本或数值。文件与日志统一右栏沿用现有授权和有界预览。

设置通过唯一用户配置入口保存有效字段或合法关联组，并独立投影持久事实和当前应用事实；活动任务和已启动进程保持旧快照，在各自安全边界更新。界面控制命令与真实提交分离，只有成功提交清理其所属已发送草稿。

视觉优先级为源需求的行为与冻结约束、三份正式 PNG、V4 静态样式。原型里的模拟搜索/保存、侧栏归档、General 附件、示例统计与连接状态均不是额外功能合同。

## 能力欠账

**无。** 已核对当前欠账清单，本包没有新增、改变或回补因后置能力未实现而刻意搁置的必需子功能，清单保持不变。

## Out of Scope

General 完整工具/附件/私人助理、多端通知与同步、Memory/Skill/MCP/Subagent/Multi-Agent；独立搜索数据库或后台索引；第二套 Agent/History/权限/配置体系；可写 Git、撤销编辑器、Worktree 和完整历史 Diff 版本；无证据的大规模目录重排、安全扩建和删除依赖。不得改变已有 Coding 工具与权限语义或跨进程恢复承诺。

## 验收标准

源需求 R01–R21 由上述 Task 完整覆盖，A01–A23 逐项映射到 [Checklist](T12-Desktop功能补齐与工程收敛-checklist.md) 的可观察行为、方法与通过条件。须有真实 General Provider 流式请求、真实 Git 工作区与 packaged 审阅、会话搜索/归档/重启/恢复联动及三视图真实 Desktop 对照；Mock、原型截图和组件存在不能代替这些证据。

公开正常/关键失败、架构和 Desktop 回归按风险与要求通过，清理项具有真实调用证据，相关用户/技术/当前事实文档与源码一致。外部条件未执行的项目保持未勾选并明确限制；不能声称整包完成。用户首次派发后冻结任务文档，只允许勾选现有验收项和追加同名反馈；包级结束与归档由用户决定。
